<h1 align="center">Motif</h1>

<p align="center">
  <i>An Android app for creating expressive, device-aware Material 3 wallpapers.</i>
</p>

Motif lets users generate a composition from shapes, colours and images, then refine it directly on a canvas. Objects can be moved, resized, rotated, recoloured, layered and saved as reusable presets.

## Status

In early development. **Application does not actually do anything right now.**

## Goals

- Generate attractive abstract wallpapers from curated Material-inspired rules.
- Support custom canvas sizes, including folded and unfolded foldable layouts (since I have a Fold5).
- Make direct manipulation feel natural on touchscreens.
- Export and apply wallpapers.

## Stack

- Kotlin
- Android Studio
- Jetpack Compose
- Compose Canvas and pointer input
- Android WallpaperManager
- Room or DataStore for local projects and presets

See [ROADMAP.md](ROADMAP.md) for the planned feature milestones.
